Printing

Print Studio prints through your browser's print dialog, which uses the printers installed on your system.

No printer installed?

Use the uprint companion tool (same repo) to add any network printer with zero drivers, zero login:

uprint discover
uprint install --printer "Office LaserJet"

Then it appears in your browser's print dialog automatically.
